# Data

This folder contains the master analytical dataset supporting **ESG Decoded – Issue 01: Infosys Limited (FY2024–25).**

The workbook serves as the **single source of truth** behind every deliverable in this repository, including the executive infographic, analyst report, presentation deck, and ESG scorecard.

---

# Workbook

**ESG_Metrics_Infosys_FY2025.xlsx**

This workbook consolidates every metric, calculation, and assessment used throughout the ESG Decoded analyst series.

# Workbook Structure

| Worksheet | Description |
|------------|-------------|
| README | Workbook overview, conventions, and methodology notes |
| Company_Overview | Company profile, headquarters, market capitalization, employees, reporting standards, and key facts |
| Environmental | Scope 1 & 2 emissions, renewable electricity, water, waste, carbon neutrality, Net Zero targets, and year-over-year analysis |
| Social | Workforce diversity, board diversity, recognitions, CSR initiatives, and employee metrics |
| Governance | Board composition, ESG oversight, governance policies, ethics, and compliance |
| Materiality_Assessment | Material ESG issues with issue-level materiality ratings |
| KPI_Tracker | Progress against sustainability goals and long-term ESG commitments |
| Trends_5Y | Five-year renewable electricity trend and ESG milestone timeline |
| ESG_Heatmap | ESG issue prioritization using risk and opportunity mapping |
| Risks_and_SWOT | Key ESG risks, red flags, and SWOT analysis |
| ESG_Scorecard | Weighted pillar scores, overall ESG score, momentum score, and analyst verdict |
| Peer_Benchmark | Comparative assessment of Infosys, Wipro, and TCS using the same scoring framework |
| Framework_Alignment | Alignment with BRSR, GRI, CDP, TCFD, and ISSB reporting frameworks |
| Data_Quality | Confidence assessment and disclosure quality evaluation |
| Sources | References, source documentation, and analytical disclaimers |

# Data Sources

The workbook has been compiled from publicly available corporate disclosures, including:

- Infosys ESG Report FY2024–25
- Infosys Integrated Annual Report FY2024–25
- Business Responsibility & Sustainability Report (BRSR)
- Global Reporting Initiative (GRI) disclosures
- CDP disclosures (where applicable)
- Infosys Investor Relations publications

Peer benchmarking has been developed using publicly available FY2024–25 disclosures for Infosys, Tata Consultancy Services (TCS), and Wipro.

---

# Data Conventions

- **Blue values** represent manually extracted or estimated values from publicly available sources.
- **Black values** are calculated automatically using Excel formulas.
- Values prefixed with **"~"** indicate best-available public estimates where exact figures were not disclosed.
- FY2024–25 refers to the fiscal year ending **31 March 2025**.
